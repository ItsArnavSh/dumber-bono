## What all data is needed?

### Motion Packet
Physics Data Pretty Much
All the location, velocity, g forces, and orientation data
For every Car

#### What is needed here:
- Coordinates(pair with fastf1 turn data)
- Velocity Data Along with forward velocity
- Orientation Data

### Session Packet
Session State
All the menu settings specified here, and other post event stuff

#### What is important
- Game Paused, for operations
- Pit Window
- Track Temperature, Air Temperature
- Weather Forecast
- Sector 2 and Sector 3 Distances

### Lap Data

#### What is important

- Distance in current lap in meters
- Safety Car Delta
- Car Position
- Pit Lane Status, number of stops, pit lane timings  
- Speed of Track
